# 固定绝对布局（强制规范）

> **要求**：每次实验开始、窗口出现后，先把窗口钉到下面的固定位置；之后所有点击/截图一律用**绝对屏幕坐标**。
> 不再每次重新标定；只有窗口被程序/用户移动或 DPI/分辨率变化时才重新 `pin_layout`。

## 0. 一页速查

```
主窗   误差配套实验       -> (0, 0)        1782 x 1295
数据表 实验数据表格       -> (1900, 0)     1174 x 963
大视图 带孔薄板 / 100张纸 -> (1900, 1000)  1406 x 1096
```

```bash
cd <workspace>/tools/framework
py -3 -I tools/pin_layout.py          # 钉窗口 + 输出 hwnd / layout.json
py -3 -I tools/pin_layout.py --check  # 只检查当前位置
```

- 大视图要在主窗双击物体打开后再钉；两个大视图（薄板/纸）会占同一位置，`ui.exe front <hwnd>` 决定当前操作哪个。
- 每次点击/截图前先 `ui.exe front <目标 hwnd>`，避免被其它窗口遮挡。

### 卡尺（BAML 精确几何，已验证）

- 可见仪器画布 `YBKCCanvas` 在 MainCanvas (7,120)，MainCanvas 屏幕原点 ≈(296,60)，DPI 系数 1.75，比例 `2.2067 canvas/mm`。
- **解锁旋钮 `XuanNiu`**：18×18 @ canvas(138,37) → 屏幕中心 **(565+1900, 350+1000) = (2465, 1350)**，右键解锁（左键锁定）。
- **拖动面 `DragRect`**：31×31 @ canvas(177,114) → 屏幕 y≈1497，x 中心随读数移动：
  `x_screen ≈ 1928 + 1.75*(177 + value*2.2067) + 27 ≈ 645 + value*3.86`
  （value 为 mm；从 x=645 开始拖，向右拖=开口增大，向左=减小）。
- 拖动后读 `ValueText`（`读数：xx.xxxmm`）即可。
- **放置判定**（反编译 `GB_all.cs`）：
  - 外量爪 `OuterCanvas`（宽/深用）：屏幕约 x 453..599、y 196..354；要求 **物体值 ≥ 开口**，否则“放不进去”。
  - 内量爪 `InnerCanvas`（孔径用）：屏幕约 x 453..599、y 506..628；要求 **物体值 ≤ 开口**。
  - 放置仍需按截图微调落点；本轮未完成实际放置验证，优先用只读真值。

### B 类不确定度表（0 分，但要求填全）

- 薄板 `(1)`：3 行（钢直尺/游标卡尺/千分尺）× 4 列（(Δ仪/L)²、(Δ仪/B)²、(Δ仪/H)²、(nπDΔ仪/(2LB))²）。
  顶部状态下单元中心：x=2282/2422/2562/2714，y=263/302/340（屏幕绝对）。
- 纸 `(1)`：3 行 × 3 列；底部状态下 x=2282/2422/2562，y≈-22/17/55（第一行已滑出视口）。
- **因为存在滑出视口的格子，不用坐标点击**：`tools/live_fill_b_tables.py` 通过 UIA
  `ValuePattern.SetValue` 按表格容器内的 Edit 顺序（列优先，每列 3 个仪器行）写入，任何滚动位置都可执行。
- 值来自 `fill_values.json` 的 `table1/table3`，格式与客户端 `GetInsUncertain -> ToUncertainty(...,2)`
  一致（2 位有效数字、纯小数）；脚本会读回校验。

## 3. 固定布局下的标准填表序列（约 1 分钟）

```bash
cd <workspace>/tools/framework
py -3 -I tools/pin_layout.py                     # 1) 钉窗口
py -3 -I tools/uia_fill_all.py                   # 2) 101 字段（含 B 表），UIA 写入+读回
py -3 -I tools/verify_table.py --pid <MainPID>   # 3) UIA 全量核对（101 项 + 小数位）
# 4) 点 (2990,930) 提交 -> 弹窗“提交成功” -> 点“确定”
```

截图（可选）：`scroll_data.py top` / `paper_b`（纸 B 表全表）/ `bottom`。

旧坐标脚本（`live_fill_gb/gb_stats/paper/b_tables`）仅空表兜底；**已填格键盘无法选全**，不要用于重填。
