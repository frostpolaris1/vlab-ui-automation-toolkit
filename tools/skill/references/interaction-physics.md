# 真实物理 → 模拟操作映射（会话2 实测，误差配套）

总原则：模拟遵循现实仪器物理逻辑，只是老开发把现实手法映射成程序控件。
**以真实手法思考 + 每步截图目视确认；程序读数/UIA 值只作旁证（会残留/过期）。**

## 千分尺（螺旋测微器）
控件分解（目视）：
- 测砧(anvil)=左金臂端银面；测微螺杆(spindle)=左端银杆面；两者之间=测量间隙。
- 锁紧柄=金座上的**圆钮带指针**：**指针往下=锁紧，往右=松开**；交互为**右键点击=解锁、左键点击=锁定**（程序提示，初态=锁定）。左键点击/拖动不会扳动指针，必须右键。旋转前目视确认指针朝右；锁着时转任何筒都无效。
- 旋转操作点=**荔枝纹滚花筒/棘轮**（右侧滚花）。**微分筒锥面(带30/35刻度)不是操作点**；锁钮只改指针不改读数。
- 交互提示「左键按下顺时针旋转，右键按下逆时针旋转」仅在按钮交互后瞬现（悬停不出）。
- 实测方向：荔枝纹**左按住=张开(读数增)**、**右按住=闭合(读数减)**（与提示字面相反，以实测为准）。
- 速率≈0.09 mm/s（按住时长×0.09）。

**bug/限制**：input 的长静默 hold（按下后 Sleep 无移动消息）会「转一半停住/卡死」。
→ 真实棘轮=一下一下拧：用**多次短按**(300~800ms/次)循环，而非一次长 hold。scripts/input2.exe 提供 `hold X Y ms [0左|1右]`。

**真实测量手法**：
1. 选测量项 radio + 点千分尺图标 → 仪器出现。
2. 目视锁向=右(松)；若往下先短按锁钮扳到右。
3. 短按左张开到明显大于物体（目视刻度主尺+微分筒）。
4. 从待测盒拖物体入间隙；**目视**确认物体在测砧/螺杆之间、盒空。
   - 「物体放不进去」≠单纯厚度；开口够大仍拒 → 命中区与视觉间隙中心偏移，经验扫点+目视。
   - 失败后物体留在场景、盒空 → 再拖要抓场景里物体当前位，或 btnOut 复位+重点仪器图标。
5. 短按右分段闭合；**读数(目视刻度)不再变化=贴紧**，平台值=厚度。
   - 闭合持续下降穿过预期值 → 物体未登记入隙，回第4步。
6. 重复测量=btnOut 复位→重点图标→重放→重闭（或按 sim 允许的重复方式）。

## 移出物体 / 复位
- `btnOut`(移出物体) **同时移除仪器与物体**；复位后必须重新点仪器图标才出现仪器。
- **仪器状态会保留**：复位重点图标后，千分尺开口读数与锁定状态仍在（不是回到初始值）。重测前先读 ValueText2 + 目视刻度确认当前开口，再决定张开量。
- 复位不清空 ValueText2/MessageText（残留旧值）→ 勿信。

## 拖拽卫生
- 起点/终点避开旋转区(滚花/棘轮/锁钮)，否则误触旋转使读数跳变。
- 抓待测盒内物体细线中心；释放点在间隙/测量带。
- 直尺测量带 y≈571（案例）；千分尺间隙中心≈大视图 win(462,465) 但命中区可能偏移，需目视迭代。

## 卡尺 / 直尺

### 卡尺（2026-11-18 二轮：BAML 精确几何，已实测）
- 读数=主尺+副尺(游标) 0.02mm；也可直接读 UIA `ValueText`（`读数：xx.xxxmm`，实测随游标变化）。
- 画布：`YBKCCanvas` 615×360 @ MainCanvas(7,120)；MainCanvas 屏幕原点≈(296,60)，DPI 1.75，比例 `2.2067 canvas/mm`。
- **解锁旋钮 `XuanNiu`**：18×18 @ canvas(138,37) → 视图相对中心 **(565,350)**；
  **右键=解锁，左键=锁定**（ToolTip「锁定旋钮：左键点击锁定，右键点击解锁」）。初态锁定。
- **拖动面 `DragRect`**：31×31 @ canvas(177,114)，随读数右移：
  视图相对 `x ≈ 645 + value*3.86`，`y ≈ 497`；**向右拖=开口增大**，向左=减小。
  可从可见的滑块/微调轮位置直接起拖；拖后看 `ValueText`。
- **放置判定**（`GB_all.cs` oD78d93w4）：
  - 外量爪 `OuterCanvas`（宽度/深度）：视图约 x 453..599、y 196..354；要求 **物体值 ≥ 开口**。
  - 内量爪 `InnerCanvas`（孔径）：视图约 x 453..599、y 506..628；要求 **物体值 ≤ 开口**。
  - 不符合 → “物体放不进去”，物体回盒；本轮（11-18 二轮）落点多次未命中，**实际放置仍是开放项**，
    优先用只读真值；下次先用截图确认爪口再小步试落点。
- 直尺读数=放大镜绝对 cm 左/右缘相减（数字读数恒 0 不可信）。
- **直尺放大镜是可左右拖动的放大矩形**（悬停提示「左右拖动矩形区域，改变其放大位置」）：
  拖动只改变放大的刻度区域，不是数字读数；与概览刻度不同源，禁止用概览像素换算 cm。
  像素法交叉校验：主刻度间距≈38.8px/cm（板长实测≈13.9cm，真值 139.7mm）。
- 隐藏考察点**只查小数位、不是行为检测**（薄板宽 2 位、薄板厚 3 位、纸厚 3 位）；
  真实测量仍是首选，交互受阻时可用只读真值兜底并在报告中注明来源。
