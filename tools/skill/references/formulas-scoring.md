# 公式与评分（误差配套类长度测量实验）

## 仪器 B 类仪器误差 Δ仪
- 钢直尺(米尺) 分度1mm，Δ仪=0.2mm
- 游标卡尺 分度0.02mm，Δ仪=0.02mm
- 螺旋测微器(千分尺) 分度0.001mm，Δ仪=0.004mm
- B 类不确定度 ΔB = Δ仪/√3

## 直接测量量统计（n=6 次）——以客户端实际判分为准
- 平均 x̄ = Σx/6
- 标准差 S = sqrt(Σ(x-x̄)²/(6-1))
- **A 类 ΔA = S（不是 S/√6！）**：`Main.exe GetUncertainA` 返回样本标准差 S，`GetStd` 把 S 直接当 ΔA 的标准答案；S 字段与 ΔA 字段同值。
- 合成 Δ = sqrt(S²+ΔB²)（不是 sqrt(ΔA²+ΔB²) 的教材写法，数值上同，因为 ΔA=S）
- **6 次同值时 S 可能是浮点残留**（如 1.996×6 → 2.4e-16），客户端 `ToUncertainty(...,2)` 会给出 `0.00000000000000025` 这类极小字符串；ΔA 字段请按该字符串填，不要手填 0（百分比判据会失分）。

## 间接量（体积）
- 带孔薄板(n 孔)：V = L*B*H - n*(π*D²/4)*H
  ΔV/V = sqrt((ΔL/L)²+(ΔB/B)²+(ΔH/H)²+(nπDΔD/(2LB))²)
- 一张纸(累积法测100张)：V = L*B*H/100
  ΔV/V = sqrt((ΔL/L)²+(ΔB/B)²+(ΔH/H)²)
- ΔV = V*(ΔV/V)；表达式 V±ΔV

## B 类配套表（表1/表3）
- 表1(薄板) 每仪器行：(Δ仪/L)², (Δ仪/B)², (Δ仪/H)², (nπDΔ仪/(2LB))²
- 表3(纸) 每仪器行：(Δ仪/L)², (Δ仪/B)², (Δ仪/H)²
- 用 Δ仪（非 ΔB）代入；保留≥6位小数避免舍入判错。
- **客户端标准用名义尺寸**（薄板 14.0/3.8/0.2/0.7 cm；纸 24.0/17.0/0.75 cm），不是会话真值；该表 0 分，填名义值即可。
- 客户端 `GetStd` 对 GZC/YBKC 行的 `index` 不自增（代码 bug），标准答案可能只按 L 列算；0 分表，不影响总分。

## 仪器选择规范（不确定度均分原理）
- 薄板：L=钢直尺(A)、B=游标卡尺(B)、H=螺旋测微器(C)、D=钢直尺(A)
- 纸：L=钢直尺(A)、B=钢直尺(A)、H=螺旋测微器(C)
- 选择空填大写字母 A/B/C。
- **纸宽 B 的 Δ仪=0.2（直尺），不是卡尺的 0.02**。2026-11-18 实战第一次提交把纸宽套成 0.02，`PaperVRelativeUncertain` 算成 0.00058（客户端标准 0.00089）、`PaperVUncertain` 1.8（标准 2.8），审计 94 分；改成 0.2 后重新提交成功。脚本里要按实验分段给误差字典：薄板 L0.2/B0.02/H0.004/D0.2；纸 L0.2/B0.2/H0.004。

## 评分容差（相对真值%，满/半）示例（误差配套）
- 薄板6×：L 0.5/1、B 2/5、H 0.3/0.6、D 5/10
- 纸6×：L 0.5/1、B 0.5/1、H 0.2/0.5
- 平均/ΔA/ΔB/Δ/rel/ΔV 多 5/10；V 3/5；表达式 3 分；表1/表3 0 分（仍需填）
- 选择每空 2 分；卡尺/千分尺"读数是否准确"另计（需真实操作仪器）
- 真值=会话随机（内存提取），参考值仅近似；以提取真值填表。

## 数据表结构（误差配套）
薄板节：表1(3行×4列) → 选择(2)-(5) → 6×表(L/B/H/D×6) → 统计(7)-(30)
纸节：表3(3行×3列) → 选择(2)-(4) → 6×表(L/B/H×6) → 统计(6)-(12)
统计含 平均/S/ΔA/ΔB/Δ 每量 + V/ΔV/V/表达式。

## 表达式（重要）
- 客户端 `GetStd` 用**学生自己填的 V 和 ΔV** 拼 `V±ΔV`，V 的小数位 = |ΔV 的小数位|；不是与真值比较。
- 因此表达式只要与自己的 V/ΔV 自洽、格式正确即可；`±` 用剪贴板，读回码点 177。
- 例：V=10189.59、ΔV=20 → 表达式 `10190±20`（V 取 0 位小数）；V=3050.98、ΔV=1.8 → `3051.0±1.8`。
