# 误差配套实验：离线准备 + 重启后执行手册

> 目标：用**真实仪器测量**的数据，按客户端实际判分逻辑，快速、可复核地填完并提交。
> 本手册基于 `Main.exe` 反编译（`main_try.cs`）与 `ExamConfig_3.xml`，不是按教材公式猜的。

---

## 0. 先记住 4 个“和教材不一样”的点

1. **ΔA = S，不是 S/√6**。客户端 `GetUncertainA` 返回样本标准差 S；`GetStd` 把 S 直接当 ΔA 的标准答案。
2. **ΔB = Δ仪/√3，Δ = √(S² + ΔB²)**，且客户端会用 `ToUncertainty(...,2)` 做“2 位有效数字、向上取整”的格式化。
3. **表达式是格式检查**：客户端用**你自己填的 V 和 ΔV**拼 `V±ΔV`，V 的小数位 = |ΔV 的小数位|。所以表达式要和自己的 V/ΔV 自洽。
4. **隐藏考察点只看小数位**：薄板宽 6 个数必须恰好 2 位小数；薄板厚、纸厚必须恰好 3 位。用卡尺/千分尺真实测量并保留尾零即可。

> 另外：6× 格没有“互不相同”校验；重复同值允许。但 6 次同值时，客户端算出的 S 可能是 `2e-16` 这种浮点残留，不是精确 0；脚本会按客户端算法给出精确字符串（如 `0.00000000000000025`）。**S 字段 0 分，ΔA 字段 1 分；ΔA 请用脚本值，不要手填 0。**

## 1. 现在（服务器维护期）能做的离线准备

### 1.1 准备实测记录文件

复制 `measurements.example.json` 为 `measurements.json`，把 6 次读数填进去（单位 mm）：

```json
{
  "paper": {"L": [6 个], "B": [6 个], "H": [6 个]},
  "gb":    {"L": [6 个], "B": [6 个], "H": [6 个], "D": [6 个]},
  "n_holes": 5
}
```

- 读数按仪器显示记录；脚本会按目标精度四舍五入（L 1 位、板宽 2 位、厚度 3 位、孔径 1 位、纸 L/B 1 位、纸厚 3 位）。
- 如果已知会话真值（只读内存/本地考卷），可加 `"truth"` 字段，脚本只用来警告偏差，不参与填表。

### 1.2 生成填表字符串

```bash
python -I build_fill_plan.py measurements.json fill_values.json
python -I gen_field_map.py ../data/package/ExamConfig_3.xml fill_values.json
```

产出：

- `fill_values.json`：每个字段的**精确字符串**（6× 格、平均、S、ΔA、ΔB、Δ、V、ΔV/V、ΔV、表达式、B 类表）。
- `FIELD_MAP.md`：界面顺序 + 字段名 + 分值 + 填法。

### 1.3 离线自测（用包内样例会话）

包内 `ExamConfig.bin` 解密后带一套样例标准答案：薄板 `139.2 / 37.96 / 1.997 / 6.8`，纸 `240.9 / 170.7 / 7.501`。可以拿它做一次 dry-run：

```bash
python -I build_fill_plan.py measurements.template.json fill_values.template.json
```

看输出的 V/ΔV/表达式是否合理；这一步不接触平台，纯离线。

## 3. 测量（每量 6 次，真实 UI）

### 3.1 千分尺（纸厚 H、板厚 H）

1. 主场景双击物体 → 大视图；选「厚度测量」radio；点千分尺图标。
2. 目视锁钮：指针朝下=锁；**右键点击解锁**（指针朝右）。
3. **短按**荔枝纹/棘轮左侧张开（每次 300–800 ms，约 0.07–0.09 mm/800 ms；多次短按，不要长 hold）。
4. 从「待测物体」盒拖物体到测砧/螺杆之间；目视确认物体在间隙里、盒空。
5. **短按**右侧闭合；读数不再变化=贴紧。记录读数。
6. 零误差修正：读数含 `ZeroError=0.02 mm`；按实验要求修正后记录（纸厚容差 ±0.2%，板厚 ±0.3%，务必核对）。
7. `移出物体`（btnOut）→ 重新点千分尺图标 → 重复。注意：复位后开口/锁定状态保留，先读当前开口再决定张开量。

### 3.2 游标卡尺（板宽 B、孔径 D）

1. 大视图选「宽度测量」/「孔径测量」；点卡尺图标。
2. **右键解锁**。
3. 拖可动爪到**略小于**物体尺寸的开口（例如板宽 38 mm，先开到 37.9 mm）。
4. 拖物体进外量爪；若提示「物体放不进去」，把开口再闭合一点重试。
5. 读主尺+游标（0.02 mm），记录 **2 位小数**。
6. 孔径用内量爪：开口要 ≥ 孔径（代码条件 `obj ≤ 开口`），放入后读。

### 3.3 钢直尺（纸 L/B、板 L、板 D）

1. 大视图选「长度测量」/「宽度测量」；点直尺图标。
2. 拖物体到直尺测量带。
3. 用放大镜读**绝对 cm** 左/右缘，相减；记录 **1 位小数**。
4. 放大镜是固定读数窗+内容随光标平移，和概览刻度不同源；先用已知刻度标定一次，不要用概览像素换算。

### 3.4 记录

每测一次，把读数写进 `measurements.json` 对应数组；不要事后凭记忆补。测完 7 个量（纸 3 + 板 4）各 6 次，共 42 个数。

## 4. 计算与填表

### 4.1 生成

```bash
python -I build_fill_plan.py measurements.json fill_values.json
python -I gen_field_map.py ../data/package/ExamConfig_3.xml fill_values.json
```

检查 `fill_values.json` 的 `warnings`：

- 6 次同值 → S 可能是浮点残留；用脚本给的 S/ΔA 字符串。
- 实测均值与真值偏差超出满档 → 检查读数/单位（cm vs mm）。
- 存在非正数 → 客户端会忽略该值，重测。

### 4.2 填表顺序（界面顺序 = XML 顺序）

**薄板（61 分）**

1. `InsUncertainPara` 表：3 行（钢直尺/游标卡尺/千分尺）× 4 列（(Δ仪/L)²、(Δ仪/B)²、(Δ仪/H)²、(nπDΔ仪/(2LB))²）。0 分，填 `fill_values.json` 的 `table1`。
2. `Choose1`–`Choose4`：A、B、C、A。
3. `GBDataPara` 6× 表：行=L/B/H/D，列=次数 1..6；填 `gb.data` 的 4×6 字符串。INDEX 行是次数，不用填。
4. 统计字段 (7)–(30)：按 `FIELD_MAP.md` 顺序填 `gb.avg/S/dA/dB/d/V/rel/dV/expr`。
5. 隐藏字段不显示；6× 的小数位会自动判定。

**100 张纸（39 分）**

1. `InsUncertainPara2` 表：3 行 × 3 列，0 分，填 `table3`。
2. `Choose5`–`Choose7`：A、A、C。
3. `PaperDataPara` 6× 表：行=L/B/H，列=1..6；填 `paper.data` 的 3×6。
4. 统计字段 (6)–(12)：`paper.avg/V/rel/dV/expr`。

### 4.3 输入规范

- 网格格：`input.exe dblclick X Y` → `chord 17 65`（Ctrl+A）→ `typestr 值` → `key 13`（Enter）。
- 单值字段：同样；或 UIA setValue（但读回以截图/目视为准）。
- **保留尾零**：`38.04`、`1.996`、`7.495`；不要输入成 `38.04`→`38.0`。
- 大写 A/B/C：`chord 16 <VK>`（Shift+字母）。
- `±`：`powershell Set-Clipboard -Value 'V±ΔV'` → 双击格 → Ctrl+A → Ctrl+V；读回用 `Get-Clipboard` 码点确认 ±=177。
- 长 tiny 字符串（如 `0.00000000000000025`）：直接 `typestr` 或剪贴板粘贴；不要手填 0。

## 5. 读回与提交

### 5.1 提交前（必须）

- 逐屏截图目视核对：表1/表3、选择、6× 网格、统计、V/ΔV/表达式。
- 重点检查：
  - 6× 小数位：板宽 2 位、板厚 3 位、纸厚 3 位。
  - 选择大写 A/B/C/A/A/A/C。
  - 表达式与自己的 V/ΔV 一致（V 的小数位 = |ΔV 的小数位|）。
  - 没有空值/串值/残留旧值。
- UIA 读回只作旁证（`ValueText2`/`MessageText` 会残留）。

### 5.2 提交

- 数据表「提交」按钮（2026-11-18 实测屏幕约 (2990,930)，即数据窗相对 (1090,930)；以截图为准）→ 等「提交成功」→ 点「确定」。
- 注意：数据表的关闭/提交会触发 `SaveData` → `SaveToServer`；**没准备好不要点**。

### 5.3 提交后审计（可选但推荐）

1. 从 `%TEMP%\lab\<n>\SimExpConfig\ExamConfig.bin` 复制一份（客户端提交时会写）。
2. 解密：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File decrypt_examconfig.ps1 `
  -BinPath "$env:TEMP\lab\<n>\SimExpConfig\ExamConfig.bin" `
  -OutPath "saved_exam.xml"
```

3. 对比：

```bash
python -I check_saved_exam.py saved_exam.xml fill_values.json
```

输出逐字段 expected/actual/std/status 和估算分数。若有 MISMATCH，按字段修正后重新提交（平台会问是否替换）。

## 6. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 卡尺提示「物体放不进去」 | 开口大于物体+抖动 | 闭合一点再拖 |
| 千分尺读数不变 | 锁着 / 点空 / 窗口移动 | 右键解锁；重钉窗口；截图确认 |
| 千分尺闭合穿过预期值 | 物体未登记入隙 | 重新拖到间隙中心 |
| 数据表格子输入被拒 | 数字格只接受数字/一个小数点 | 用 `typestr` 纯数字；表达式用字符串格 |
| ± 变成 U+FFFD | GBK/输入法 | 剪贴板粘贴；读回码点 177 |
| 隐藏检查 0 分 | 6× 尾零丢失/小数位不对 | 重新输入精确字符串 |
| ΔA 字段拒绝长 tiny 值 | 输入法/长度 | 剪贴板粘贴；仍失败则填 0，接受可能 1 分/量损失 |
| 提交失败 | 服务器维护/网络/签名 | 等维护结束；不要伪造签名 |

## 7. 合规边界

- **做**：真实 UI、真实测量、按客户端实际公式计算、官方提交、只读解密校验。
- **不做**：注入/写内存/改 bin/伪造 StdResult/伪造签名/伪造数据/绕过计时/禁用录屏。
- 自动化是否被课程允许，先确认；若不允许，改用人工按本手册操作。
